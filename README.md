# Recordify Official Website 🎵

Official landing and download website for **Recordify** and **Recordify TV**.

## 🌐 Live Website
- **URL**: [https://hetansh21-pro.github.io/Recordify-Website/](https://hetansh21-pro.github.io/Recordify-Website/)

## 🚀 Features
- **Direct APK Downloads**: One-click download links for Recordify Mobile & Recordify TV.
- **Spotify AMOLED Dark Aesthetic**: High-performance, lightweight HTML5/CSS3/vanilla JS.
- **Interactive Device Showcase**: Switch between Mobile touch gestures and Android TV 10-foot remote experience.
- **Complete Feature Matrix**: 8 detailed feature cards with technical explanations.
- **Step-by-Step Installation Guides**: Simple visual walkthrough for Android phone and Smart TV sideloading.
- **Responsive & Mobile-First**: Optimized for phones, tablets, laptops, and ultra-wide displays.

## 🛠️ Local Development
To preview the website locally:
```bash
# Using Python:
python3 -m http.server 8080

# Using Node.js npx:
npx serve .
```
Then open `http://localhost:8080` in your web browser.
